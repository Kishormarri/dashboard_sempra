Step-by-Step: How to Use
Complete walkthrough — no technical knowledge required
1
🚀 Launch the Dashboard
Open PowerShell in the project folder and run: python launch_dashboard.py
Your browser opens automatically at http://localhost:5003/Sempra_CrossCycle_Summary_MASTER.html
Two background services start silently — leave the PowerShell windows open while using the dashboard.
2
🔐 Log In with Your Role
A secure login screen appears. Choose your role:
Admin — full access including SAP automation  |  Manager — view + PDF exports
Analyst — upload files + download CSV/Excel  |  Viewer — read-only access
Your session is saved automatically — you stay logged in across page reloads.
3
⚡ Click "Auto-Sync All Cycles"
One click reads all 5 Excel files from the C: drive, parses them in the browser, runs reconciliation for DM1, DM2, DM3 simultaneously, and updates all three cycle cards.
A rainbow animation plays on the button while running. Three coloured spinning sync circles appear — one per cycle — showing the match % when each completes. Entire process takes under 10 seconds.
4
📊 Read the Business View Results
Each cycle card shows: an animated match % gauge, a RAG badge (GREEN ≥95% · AMBER 80–94% · RED <80%), headline KPIs (total tables, matched, mismatched, missing), and auto-generated insight boxes that flag the most important issues automatically.
5
🔧 Switch to Technical View for Per-Table Detail
Click the Technical View tab to see a full table-level breakdown:
Set 1 — Tables in Reference List with migration data (EXP vs IMP counts compared)
Set 2 — Tables NOT in the Reference List (unexpected data — investigate)
Set 3 — Tables in Reference List with NO migration data (never migrated)
Set 4 — Tables where Export count ≠ Import count (data loss risk)
6
🔍 Drill Down into Individual Cycles
Click DM1 / DM2 / DM3 in the navigation to open that cycle's detail page. Upload new Excel files via drag-and-drop anytime. Search and filter the full table list. Click any row to open a drill-down modal with record-level detail and visual chart. Download filtered subsets as CSV or Excel using the export buttons.
7
📤 Export for Leadership Presentations
Press Ctrl+P → Save as PDF for a clean, print-ready leadership report. The dashboard switches to white background with all colours preserved for a professional output. Or use the CSV / Excel export buttons per analysis set. Full export (all cycles, all sets in one Excel file) available from the master dashboard.
8
🔄 Auto-Refresh Keeps Data Current
The dashboard auto-refreshes every 2 minutes — a countdown timer is shown in the toolbar. A red dot appears when refresh is <60 seconds away. Click Pause to freeze the view during a presentation. All results persist in browser localStorage — survive page reloads without re-syncing.

Technical Architecture
How the system works — for technical reviewers
YOUR BROWSER (HTML + JavaScript + SheetJS v0.18.5) Sempra_CrossCycle_Summary_MASTER.html ← Main dashboard, all 3 cycles Sempra_DM1/DM2/DM3_Dashboard.html ← Per-cycle detail pages │ │ fetch("http://localhost:5002/file?cycle=DM1&type=ref") │ gzip-compressed Excel bytes ← ETag 304 caching ▼ FILE WATCHER BRIDGE (Python Flask — port 5002) automation/file_watcher_bridge.py ✔ In-memory cache ✔ Gzip compression ✔ ETag / 304 Not Modified │ │ reads raw Excel bytes from disk ▼ LOCAL FILE SYSTEM (C:\Users\KishorMarri\.bob\) DM1\Reflist_m1.xlsx + DM1_ES2-SQ1 Export-Import.xlsx DM2\DM2 REF.xlsx + EXPORT IMPORT_DM2.xlsx DM3\ref dm31.xlsx + DM3_EXPORT_IMPORT_LOG.xlsx SAP BRIDGE (Optional — Python Flask — port 5001) automation/sap_bridge.py Method 1: EM_GET_NUMBER_OF_ENTRIES (SE16N internal FM) Method 2: RFC_READ_TABLE (standard fallback) Method 3: BBP_RFC_READ_TABLE (alternative fallback)
🔒
Security: All Flask servers bind to 127.0.0.1 (loopback only) — not reachable from the network. No Sempra data ever leaves the local machine. SAP credentials entered in-browser are never written to disk. No firewall changes required.
