🏠 SAP IS-U CIS — Utility Types, SPARTE Codes & Object Hierarchy Overview
SPARTE (Division) is the single most important configuration field in SAP IS-U. It drives which rate categories, billing schemas, device types, and meter reading routes are valid for each customer. Set at Connection Object (EOBJK) and inherited by Premise, Device Location, Device, and Contract.

IS-U Object Hierarchy — Same Structure for ALL Utility Types

Key rule: The physical object hierarchy (Connection Object → Premise → Device Location → Device) is identical for all six utility types. The SPARTE code flows top-to-bottom and determines which config tables, rate categories, and device types are valid at each level.
