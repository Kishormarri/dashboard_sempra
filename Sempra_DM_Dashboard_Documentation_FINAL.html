How Data Is Matched — Visual Guide
How the Reference List is compared with Export and Import data — what business people see

The Two Input Files per Cycle

📋 File 1 — Reference List (REF)
Master list of all SAP tables expected to be migrated
Contains: Table Name + expected record count
Prepared by the migration team before cutover
Example: Reflist_m1.xlsx for DM1
📤 File 2 — Export/Import Log (EXP/IMP)
SNP migration tool output after cutover runs
Contains: Table Name + EXP rows + IMP rows + counts
Shows what was actually exported and imported
Example: DM1_ES2-SQ1 Export-Import.xlsx

Source vs Target Count Comparison
How SAP source system counts are verified against the target after migration
Why Source vs Target Matters
The Source count is how many records existed in the old SAP system (ES2) before migration. The Target count is how many arrived in the new SAP system (SQ1). If these numbers don't match, records were lost or duplicated during the migration — this must be investigated.

Step-by-Step: How to Use the Dashboard
Complete walkthrough — no technical knowledge required
1
🚀 Launch the Dashboard
Open PowerShell in the project folder and run: python launch_dashboard.py
Browser opens automatically at http://localhost:5003/Sempra_CrossCycle_Summary_MASTER.html
Two services start in background — leave the PowerShell windows open while working.
2
🔐 Log In with Your Role
Login screen appears. Select your role: Admin (full access) · Manager (view + PDF) · Analyst (upload + download) · Viewer (read-only). Session saved — stays logged in across reloads.
3
⚡ Click "Auto-Sync All Cycles" — One Button Does Everything
One click reads all 5 Excel files from C: drive, matches REF tables against EXP/IMP data for all three cycles simultaneously, and updates all gauges and RAG badges. Rainbow animation plays while running. Completes in under 10 seconds.
4
📊 Read the Business View — RAG Scorecards
Each cycle card shows: match % gauge, RAG badge (GREEN ≥95% · AMBER 80–94% · RED <80%), KPIs (total tables, matched, mismatched, missing), and auto-generated insight boxes flagging key issues — no manual analysis needed.
5
🔧 Switch to Technical View — Per-Table Detail
Click Technical View tab. See every table with EXP count, IMP count, Source count, Target count, and variance — in a searchable, sortable table. Click any row to drill down to record-level detail with a visual chart.
6
📤 Export for Leadership — Ctrl+P → Save as PDF
Press Ctrl+P → Save as PDF. Dashboard auto-switches to clean white background with all colours preserved — professional output ready to share with sponsors and clients. Or download CSV/Excel from any set using the export buttons.

Security & Data Privacy
No cloud, no external calls — all data stays on the Sempra laptop
Security Statement
No Sempra data ever leaves the local machine. All Excel files are served via a localhost-only Flask server (127.0.0.1 — not reachable from the network), parsed entirely in the browser, and results stored only in browser localStorage. There is no cloud API, no telemetry, no external network calls.
RiskMitigation
Data leaving the machineAll Flask servers bind to 127.0.0.1 only — not accessible from network
External API callsSheetJS is a one-time CDN fetch (library only) — no data sent outbound
SAP credentialsEntered in-browser only, passed to localhost only, never written to disk
Network port exposurePorts 5001/5002/5003 all loopback only — no firewall changes required
File accessOnly config-listed files accessible — no directory traversal possible
