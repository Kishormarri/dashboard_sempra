📐 EMIGALL Configuration Guide — T7XEMI* Tables
EMIGALL (T-code: EMIGALL or ISU_EMIGALL) is SAP's native IS-U migration workbench. It processes migration objects through a pipeline: Source Data → Value Mapping → Business Validation → Target Table Load → Error Log.
Key EMIGALL Configuration Tables
T7XEMI01Migration Object definitions — STATUS=A to activate
T7XEMI02Field Mappings — source field → target SAP field
T7XEMI03Value Translation — source codes → SAP codes (e.g., R→ZRES)
T7XEMI04Load Program assignments per migration object
T7XEMI05Object processing status and restart markers
T7XEMI06BAdI configuration for custom validation
T7XEMERRError log — row-level errors per run
T7XEMLOGSuccess log — successfully loaded records
EMIGALL Processing Flow
Source File / Staging Table→ BODS Extract & Transform→ EMIGALL Upload Interface→ T7XEMI02 Field Mapping→ T7XEMI03 Value Translation→ Business Rule Validation (BAdI)→ Test Run (no commit)→ Fix T7XEMERR Errors→ Production Run (commit)→ T7XEMLOG Success
Step-by-Step EMIGALL Setup for a New Object
  1. T-code EMIGALL → Create migration object → Enter object code (e.g., ZBUPA) and description
  2. Set T7XEMI01.STATUS = A (Active). Transport DEV→QA→PROD via standard TR.
  3. T7XEMI02 — Define field mappings: for each target SAP field, map source field name. Mark mandatory fields (MFLAGS=M). Add default values for fields not in source.
  4. T7XEMI03 — Value translation: run frequency analysis in BODS on coded source fields. Map every distinct source value to SAP code. Unmapped values → T7XEMERR at runtime.
  5. T7XEMI04 — Assign load program (ABAP program that executes the BAPI calls). Pre-built programs exist for standard IS-U objects.
  6. BAdI ISU_EMIGALL_BADI — Implement custom validation class if business rules beyond standard EMIGALL are needed (e.g., cross-object checks, enrichment from Z-tables).
  7. Upload staging data file → T-code EMIGALL → Execute in Test Mode (TESTLAUF=X) → Check T7XEMERR → Fix → Re-test until 0 errors.
  8. Execute Production Run (TESTLAUF=space) → Monitor SM37 background job → Verify T7XEMLOG count = expected.
  9. Post-load: update cross-reference Z-table (Z_XREF_<OBJECT>) with old legacy ID → new SAP number mapping for all downstream objects.
EMIGALL Error Analysis
After each test run: SE16 T7XEMERR → Export to Excel → GROUP BY error message → Fix systemic issues (value mapping gaps, config missing) first, then data issues.
