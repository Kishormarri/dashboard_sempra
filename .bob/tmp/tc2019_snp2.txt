Objective

03.02.2020
49
Description

Parameter
Encryption Password
ENCRYPTION_PASS
The entry of an encryption password serves the protection of 
personal data prior to export and the decryption of data during 
import
The encryption is activated by entering a password in the scenario 
and requires additional run time of approximately 30%
The table that is to be encrypted must be maintained in 
/SNP/TE00TABENCR
Note: If you use encryption, you should define the password only 
once, otherwise problems will occur with data that has already been 
exported

Run Parameter – In-Memory Generation 
03.02.2020
52
Description
Value
Parameter
In-Memory Generation
IN_MEMORY_GENERATION
Max. no. of in-memory prog
5
MAX_IN_MEMORY_PROGRAMS
In-memory generation shortens the generation time of the 
programs and can be activated using this parameter
The Max no. of in-memory prog parameter adjusts the number of 
programs that are held in the storage simultaneously. An increase 
of the parameter can achieve an improved runtime, if many small 
tables are processed. The value range is between 2 and 35.
Note: Increasing the value can lead to short dumps in connection with 
the program buffer (memory overflow).

=====PAGE 53=====
In-Memory Generation 
03.02.2020
53
In-Memory Generation
Persistent Generation
Programs/source texts are saved in the SNP table 
/SNP/PX0XMEMREP and are only loaded into the 
storage during run time
Advantage:
Generation can be parallelized and thus greatly 
shortened (up to 1/6)
Disadvantage: 
Export/import programs cannot be viewed in SE38 
Currently not yet applicable across the board
Standard Version 
Reports are created on the satellite system
Advantage: 
Programs can be viewed in SE38 and debugged, if 
necessary 
Disadvantage:
Only partially parallelizable The start of many tables 
is subject to severe delays
