Maintain Scope
A created global event is effective for all tables.
By limiting the scope, you can determine for 
which modules, objects or tables the global event 
should be effective.
Maintaining can be done by right-clicking on the 
global event in the scenario tree or under global 
events using the button Maintain Scope. 
If no module, object or table is entered, the scope 
is the entire scenario (all tables).

entire event for all tables.

Indexes of database tables
The index of a database table supports a faster
selection of rows. 
It comprises of selected fields of a database table, of
which a copy is created in a sorted order.
An additional field contains an indicator to the actual
table rows.
The sorting enables fast access to the rows in the
table, e.g. via a binary search.  
A database table has at least one primary index
defined by the key fields and can optionally have one
or multiple secondary indexes.
