🔧 BODS Configuration Checklist

01
SharePoint Source Connection
Create Datastore in BODS Designer pointing to SharePoint file location. Set file format (CSV/Excel), delimiter, header row flag, encoding (UTF-8).
02
SAP Target Datastore
Create RFC/IDOC Datastore to target SAP IS-U system. Configure BODS Application Server, System Number, Client, credentials, and RFC timeout.
03
Z-XREF Staging Tables
Confirm ZXREF_BP, ZXREF_CA, ZXREF_CO, ZXREF_PREM exist in SAP. BODS writes legacy→SAP key mappings here for downstream objects.
04
Field Mapping (T7XEMI02)
Map every source column → EMIGALL target field. Use SE16 to verify T7XEMI02 entries per container. 100% coverage required.
05
Value Mapping (T7XEMI03)
Map every source code → SAP domain value. SPARTE, TARIF, ABLEINH, MSTATUS etc. Missing values cause T7XEMERR at runtime.
06
EMIGALL Test Mode Run
Execute EMIGALL with Test Mode = ON. Review T7XEMERR — fix all errors. Repeat until error count = 0 before production run.
07
Reconciliation Counts
Run SE16 on BUT000, FKKVK, EOBJK, EANL, EGERH, EABL post-load. Compare record counts vs source. Investigate any delta > 0.1%.
08
BODS Job Scheduling
Schedule BODS batch job for cutover window. Set dependency chain: BP job → CA job → Contract job → Device job → Meter Read job.
